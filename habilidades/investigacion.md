# Investigación

- Prioriza fuentes oficiales (entidades del gobierno, sitio del proveedor) sobre foros.
- Para trámites: requisitos, documentos, costo, dónde se hace (presencial o en línea),
  horarios y tiempo de respuesta.
- Para servicios o negocios: opiniones recientes (últimos 12 meses), quejas repetidas,
  datos de contacto.
- Siempre incluye los links de las fuentes.
- Si la información de dos fuentes se contradice, dilo y muestra ambas.

## Formato de entrega
- Resumen de 3 líneas con la respuesta directa.
- Detalles en viñetas.
- "Siguiente paso" concreto para el usuario.
- Fuentes.
